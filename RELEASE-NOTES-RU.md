# SelectBlocks 1.1.0 — расширение совместимости

Скачивайте только один подходящий пакет из Assets:

- **SelectBlocks_1.1.0_rootless.deb** — стандартный rootless-bootstrap, iOS 15+, arm64 и современный arm64e. Этот вариант нужен для исходной конфигурации пользователя с Dopamine/rootless.
- **SelectBlocks_1.1.0_rootful.deb** — rootful, iOS 14+, arm64 и современный arm64e.
- **SelectBlocks_1.1.0_rootful-legacy.deb** — rootful, iOS 12–13, только arm64. Для системных arm64e-приложений на A12+ с iOS 12/13 этот вариант не подходит: старый arm64e ABI не собран.

Что изменено:

- Удалено жёсткое ограничение запуска только на iOS 16; код теперь допускает iOS 12+ с учётом выбранного варианта пакета.
- UIAction заменён классической обработкой нажатий, доступной на старых системах.
- Добавлены оконный режим без UIScene и проверки доступности функций iOS 13.
- Каждый пакет собирается отдельно, с собственным диапазоном прошивок и путём установки. В CI проверяются архитектуры Mach-O и расположение библиотеки внутри DEB.
- Нет привязки к номеру версии Dopamine: используется стандартная совместимая инъекция твиков. Звуки, языковые названия и сохранения сохранены.

Границы: это расширенные цели сборки и загрузки, а не подтверждение работы на всех iOS и всех джейлбрейках. Поддержка зависит от загрузчика твиков и архитектуры процесса. Инъекция должна быть разрешена для приложения. Специальные rootHide/неполные bootstrap и обход настроек антиджейлбрейка не добавлены. 32-битные устройства, iOS ниже 12 и старый arm64e ABI iOS 12/13 не поддерживаются. Новые сочетания требуют проверки на устройстве; успешно пройденная сборка не заменяет её.

Прежние релизы оставлены для отката. Перед установкой узнайте, как запустить ваш jailbreak без инъекции твиков и удалить пакет при сбое.

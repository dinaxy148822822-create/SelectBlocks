# SelectBlocks

## [Русский — полная документация](README.ru.md) · [English — full documentation](README.en.md)

**RU:** Выдели «тетрис» — открой ретро-игру в текущем приложении. Нужны совместимый джейлбрейк и разрешённая инъекция твиков.

**EN:** Select “tetris” to open a retro falling-block game inside the current app. A compatible jailbreak and enabled tweak injection are required.

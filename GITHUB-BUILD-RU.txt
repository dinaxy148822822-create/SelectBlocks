Инструкция по сборке перенесена в docs/BUILDING.md.

Для сборки через GitHub откройте Actions > Build DEB > Run workflow.
В текущей ветке используются отдельные rootless, rootful и rootful-legacy цели.
Файлы и архитектуры проверяются автоматически. Установка и игра на устройстве
требуют отдельной проверки. Доступность и стоимость Actions зависят от
лимитов аккаунта; не подтверждайте платные операции, не проверив условия.

Секретный токен в исходниках не нужен: workflow использует GITHUB_TOKEN.
Не размещайте пароли, токены или сертификаты в репозитории.

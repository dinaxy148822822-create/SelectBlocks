Сборка через GitHub Actions — без установки WSL и Theos на Windows.
1. Создайте пустой репозиторий GitHub с веткой main (можно с README).
2. Загрузите СОДЕРЖИМОЕ папки SelectBlocks в корень репозитория.
   Makefile, Tweak.xm и Game.h должны лежать в корне.
   Обязательно загрузите папку .github вместе с workflows/build.yml.
3. Откройте Actions > Build DEB > Run workflow.
4. После успешного запуска откройте его и скачайте в Artifacts
   SelectBlocks-rootless-DEB. Распакуйте скачанный ZIP, внутри будет .deb.
Если Actions не показывает Build DEB, проверьте путь .github/workflows/build.yml.

Подписывать приложение личным Apple ID не нужно. Не добавляйте пароли,
сертификаты или секреты в репозиторий. Проект и инструменты собираются
на серверах GitHub. Доступность и стоимость зависят от текущих лимитов
вашего аккаунта и типа репозитория; проверяйте сообщения GitHub.
Сценарий использует официальные репозитории Theos и SDK, Homebrew и
официальные действия GitHub checkout/upload-artifact.

ВНИМАНИЕ: этот сценарий в GitHub не запускался. Успешная сборка не
гарантирована; если возникнет ошибка, пришлите лог красного шага.
Сам твик не испытан на iPhone; результат сборки остаётся экспериментальным.
